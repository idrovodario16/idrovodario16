NexusCore gestiona operaciones; NexusInsight transforma eventos compatibles en indicadores. Funcionan por separado y documentan su integración en [Nexus Architecture](https://github.com/idrovodario16/nexus-architecture). Las demos intercambian JSON manualmente; las APIs y el relay se ejecutan por separado. La conexión UI/API sigue pendiente.
